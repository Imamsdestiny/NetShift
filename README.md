# Subnetting for Noobs: Interactive IPv4 Calculator

A sleek, client-side subnetting calculator designed for rapid network planning and educational use. 

This tool was conceptualized to eliminate the need for outdated, ad-heavy subnetting websites. It provides instant, dynamic calculations for network ranges based on CIDR notation.

## Features
* **Interactive CIDR Slider:** Dynamically updates from `/8` to `/32` in real-time.
* **Instant Calculations:** Automatically computes Total Hosts, Usable Hosts, Subnet Mask, and Wildcard Mask.
* **Network & Broadcast Mapping:** Input a specific IPv4 address to instantly calculate the exact Network Address, Broadcast Address, and Usable Host Range.
* **Modern UI:** Responsive, dark-mode glassmorphism design.
* **Client-Side Only:** Runs entirely in the browser with no backend requirements.
